# Sony BRAVIA KDL-43W809C (2015, Full HD, "BRAVIA 2015", device SVP-DTV15, MediaTek), EU firmware, Spain
# Android TV 7.0 (API 24), build SVPDTV15_EU-user 7.0 NRD91N.S34 5.433, 1.6 GB RAM
# Same platform and package set as examples/sony-kd-49x8307c (the 4K sibling); this list starts from it.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/sony-kdl-43w809c/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/sony-kdl-43w809c/debloat.txt com.google.android.leanbacklauncher
#
# Everything is DISABLED (pm disable-user --user 0), NOT uninstalled. 100% reversible.
# Stock launcher is com.google.android.leanbacklauncher (not com.google.android.tvlauncher).
# com.sony.dtv.tvx plays TV channels and HDMI inputs: keep it. com.amazon.aiv.eu is part of Prime Video: keep it.
# com.sony.dtv.b2b.hotellanguage and com.sony.dtv.b2b.hotelmenu were already disabled at the factory.
#
# Tested 2026-10-21 on a real unit in three batches with screenshots between them, then the launcher, then a
# reboot: Netflix, TizenTube, Live TV and HDMI (com.sony.dtv.tvx, from the launcher's Inputs menu), the remote's
# app, Input and Action Menu buttons and held volume all kept working, and every package stayed disabled after
# the reboot. MemFree at Home went from ~104 MB to ~140-180 MB. The Sony Select promo tiles (Movistar+,
# Vodafone TV, Clan, Rakuten, Filmin...) go with com.sony.dtv.sonyselect.
# Launcher works with minSdk 24 (Android 7 support: java.time desugaring and LegacyFonts for Outfit); the
# Android 7's am start -W answers "Status: timeout" here, which build-and-install.sh checks with dumpsys.
# This adbd takes ONE network connection at a time: while `adb connect` holds it, tools/tv.py times out after
# 10 s ("Reading from <ip>:5555 timed out"). Run `adb disconnect <ip>:5555` before the repo's scripts.
